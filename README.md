# FastLocation

Projeto desenvolvido em Flutter para consulta de endereços por CEP.

## Funcionalidades
- Consultar endereços por CEP.
- Visualizar informações do endereço.
- Salvar e consultar o histórico de pesquisas.
- Abrir localizações no Google Maps.

## Tecnologias
- Flutter e Dart
- MobX
- Hive

## Como executar

1. Instale o Flutter.
2. Abra o projeto no VS Code.
3. No terminal, execute:

```bash
flutter pub get
flutter run -d chrome
```
